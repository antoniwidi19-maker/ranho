
# ⌘ DevSpace

> Build your future with code.

DevSpace is a modern mini learning platform for exploring the fundamentals of web development.

## ✨ Features

- Modern dark UI
- Responsive design
- Technology cards
- Search functionality
- Dynamic data loaded from JSON
- Interactive notifications
- Animated interface

## 🛠 Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Website structure |
| CSS3 | Styling and responsive layout |
| JavaScript | Interactivity and logic |
| JSON | Dynamic data source |
| Markdown | Documentation |

## 📂 Project Structure

```text
DevSpace/
├── index.html
├── style.css
├── script.js
├── data.json
└── README.md
```

## 🚀 Deployment

1. Upload all files to your GitHub repository.
2. Open repository Settings.
3. Select Pages.
4. Choose Deploy from a branch.
5. Select the `main` branch.
6. Select `/ (root)` as the folder.
7. Click Save.
